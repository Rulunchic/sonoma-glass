# My Omarchy Menu: поиск, вычисления и возможности Spotlight

Обновлено 19 октября 2026 года. Меню открывается через Super+Space.
Выражение вычисляется при вводе. Enter копирует ответ и запоминает его как `ans`.
В результатах вычислений выводится одна строка. Необязательные сведения об источнике
хранятся в данных, отдельного пункта с рекламой источника нет.

## Поддерживаемые запросы

| Возможность | Примеры |
| --- | --- |
| Арифметика и скобки | `5+5`, `(12+8)/4`, `2(3+4)`, `-2^2` |
| Степени и деление | `2^10`, `2**10`, `10//3`, `10 mod 3` |
| Проценты | `15% от 85`, `15% of 85`, `200+10%`, `200-15%`, `20 процентов от 250` |
| Корни | `sqrt(144)`, `√144`, `cbrt(27)`, `root(-8,3)` |
| Константы | `pi`, `π`, `tau`, `phi`, `2pi`, `e^2` |
| Последний скопированный ответ | `ans*2`, `ans+100` |
| Тригонометрия | `sin(pi/2)`, `cos(0)`, `tan(pi/4)`, `cot(pi/4)`, `sec(0)`, `csc(pi/2)` |
| Градусы | `sin(30°)`, `cos(60 deg)`, `sind(30)`, `cosd(60)`, `tand(45)` |
| Русские названия | `синус(30°)`, `косинус(60°)`, `тг(pi/4)`, `корень(144)` |
| Обратные функции | `asin(0.5)`, `acos(0.5)`, `atan(1)`, `atan2(1,1)` |
| Гиперболические функции | `sinh(1)`, `cosh(1)`, `tanh(1)`, `asinh(1)`, `acosh(2)`, `atanh(0.5)` |
| Логарифмы | `ln(e^2)`, `log(100)`, `log(8,2)`, `log2(8)`, `log10(1000)`, `exp(2)` |
| Округление | `round(3.14159,2)`, `floor(3.8)`, `ceil(3.2)`, `trunc(-3.8)` |
| Числовые функции | `abs(-5)`, `sign(-5)`, `min(4,2,3)`, `max(4,2,3)`, `sum(1,2,3)`, `avg(1,2,3)` |
| Комбинаторика | `10!`, `fact(10)`, `ncr(5,2)`, `npr(5,2)` |
| Целые числа и геометрия | `gcd(12,18)`, `lcm(12,18)`, `hypot(3,4)` |
| Валюты | `5 руб в дол`, `5руб в долл`, `5р в $`, `$5 в руб`, `100 RUB to USD`, `2 евро в руб` |
| Курс единицы валюты | `курс дол`, `курс евро`, `курс юаня`, `USD в RUB` |
| Длина | `5км в м`, `10 миль в км`, `32 ft to m`, `5 дюймов в см` |
| Масса | `1 кг в г`, `5 фунтов в кг`, `16 oz in lb` |
| Температура | `32F в C`, `0 C in F`, `273.15K in C`, `100 °C в K` |
| Объём | `1 л в мл`, `1 gal in l`, `1 м3 в л` |
| Площадь | `1 га в м2`, `1 acre in m2`, `1 km2 in ha` |
| Скорость | `72 км/ч в м/с`, `60 mph in km/h` |
| Длительность | `2 ч в мин`, `3 дня в ч`, `1 неделя в дней` |
| Объём данных | `1 GiB в MiB`, `1 GB в MB`, `1 MB в bit`, `1 гб в мб` |
| Энергия | `1 kWh in J`, `100 ккал в кДж` |
| Давление | `1 бар в кпа`, `1 atm in Pa`, `30 psi in bar` |
| Углы | `180 deg in rad`, `3.14159265359 rad in deg` |
| Системы счисления | `255 в hex`, `0xff в dec`, `1010 bin в dec`, `hex 255`, `255 в bin` |
| Мировое время | `время в Лондоне`, `time in Tokyo`, `время в Нью-Йорке` |
| Перевод времени | `14:00 мск в нск`, `09:30 London to Moscow`, `18:00 UTC в мск` |
| Даты | `сегодня`, `завтра`, `через 5 дней`, `через 2 недели`, `2026-12-31 - 2026-10-19` |

`sin`, `cos`, `tan` и обратные функции используют радианы. Для градусов укажите
`°`, `deg` или используйте `sind`, `cosd`, `tand`. `deg(pi)` переводит радианы
в градусы, `rad(180)` переводит градусы в радианы.

Десятичная запятая поддерживается: `2,5+1,5`, `sin(0,5)`.
В функциях с несколькими аргументами запятая разделяет аргументы: `pow(2,3)`.
Для десятичных запятых в таких функциях используйте точку с запятой:
`pow(2,5;2)` означает 2,5².

В данных латинская `B` означает байт, `b` — бит: `MB` и `Mb` различаются.
`KB`, `MB`, `GB` используют множитель 1000; `KiB`, `MiB`, `GiB` — 1024.
Галлоны, кварты, пинты и чашки в приведённых единицах американские.

Деление на ноль и выражения вне области определения не создают ложного числового
ответа. Комплексные числа и символьное решение уравнений не реализованы.

## Валюты и скорость

Курсы берутся из [официального XML Банка России](https://www.cbr.ru/development/SXML/).
На момент установки в ответе есть 55 кодов с учётом RUB. Можно использовать любой
код из текущего ответа ЦБ. Для распространённых валют добавлены русские названия,
падежи и сокращения: руб/р, дол/долл/бакс, евр, юан, тенге, фунт, лира, франк,
грн, лари, драм и другие.

Сеть не используется при наборе. Данные читаются в память заранее; обновление
курсов выполняется в фоне не чаще одного раза за шесть часов. При сетевой ошибке
сохраняется последний полный набор. Если копия старше двух суток, рядом с ответом
появляется пометка о сохранённом курсе. Это официальные курсы ЦБ, банковские цены
покупки и продажи не запрашиваются.

Смещения часовых поясов рассчитываются через системную базу zoneinfo и обновляются
каждый час; международные города учитывают текущий сезонный перевод времени.
Преобразование указанного времени использует текущую дату, а не произвольную дату
в прошлом или будущем.

Обработчик ввода выполняется внутри QML без ожидания таймера, Python и сети.
Python используется только для фонового обновления данных. Каталог приложений
предварительно загружается из DesktopEntries, включая правила скрытия и поиск иконок.

## Карта возможностей Spotlight

Перечень составлен по официальному руководству Apple для macOS Tahoe 26.
Каталог действий зависит от установленных приложений и Shortcuts, поэтому у него
нет одного неизменного списка команд для всех компьютеров.

| Возможности Spotlight | Состояние в этом меню |
| --- | --- |
| Поиск и запуск приложений с клавиатуры | Работает в Apps и общем поиске |
| Подсчёт выражений прямо при вводе | Реализовано, включая расширенные функции выше |
| Валюта, температура, расстояние, масса и другие величины | Реализовано |
| Мировые часы и конвертация времени | Реализовано для перечисленных в коде городов и зон |
| Открытие результатов через Enter, навигация стрелками | Работает; Enter на числовом результате копирует его |
| Поиск системных действий и настроек | Работает через существующие разделы Omarchy |
| Поиск файлов, папок и их содержимого | Общего файлового индекса в этом плагине пока нет |
| Предпросмотр файлов, определение их расположения | Не реализовано в этом плагине |
| Режимы Apps / Files / Actions / Clipboard | Apps и разделы действий существуют; единая панель четырёх режимов не добавлена |
| Фильтры по приложению, месту хранения, типу и атрибутам файла | Не реализованы; Apple поддерживает в том числе kind:, author:, title: и name: |
| История предыдущих поисков | Не реализована |
| Поиск и повторное копирование из истории буфера | В Omarchy есть отдельная история буфера; в общий список этого меню она не встроена |
| Действия с заполнением параметров прямо в поиске | У Omarchy часть команд открывает свои диалоги; универсальная форма действий не добавлена |
| Пользовательские короткие команды Quick Keys | Есть обычные aliases Omarchy; редактор Quick Keys не добавлен |
| Shortcuts и действия сторонних приложений | Для Linux нужны отдельные команды или интеграции |
| Действия над текстом и изображениями | В Apple: смена регистра, перевод текста, удаление фона; здесь не добавлены |
| Действия общения и медиа | В Apple: почта, FaceTime, распознавание музыки; здесь не добавлены |
| Интернет-предложения и запрос Siri | Интеграции Apple здесь не реализованы |
